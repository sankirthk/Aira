# Aira v1.0.0-beta.7.1

Tag: `v1.0.0-beta.7.1`  
Release date: `2026-05-08`

## Overview

This hotfix improves the first-use Word Tracking experience after app launch. When WhisperKit still needs to prepare, Aira now blocks the presenter session behind a clear `Getting ready...` state instead of letting the user begin speaking before word-based scrolling is ready.

## Highlights

- **Clear Word Tracking startup state.** First cold Word Tracking sessions show `Getting ready...` while WhisperKit prepares.
- **No silent non-scrolling start.** Speech-driven scrolling begins only after the Word Tracking backend reports ready.
- **No arbitrary extra countdown.** After readiness, Aira honors the configured countdown exactly, including starting immediately when countdown is set to 0.
- **One-time gate per launch.** Once Word Tracking has prepared, later Word Tracking sessions skip the readiness screen.

## Included In This Hotfix

### Word Tracking startup readiness

- Added a launch-scoped readiness flag for the Word Tracking recognition backend
- Marked Word Tracking ready after successful idle prewarm or active backend preparation
- Added a `Getting ready...` overlay for cold Word Tracking launches
- Started model-only prewarm from the readiness overlay without starting microphone capture
- Preserved normal countdown behavior after model readiness

### Tests and docs

- Added launch-policy coverage for cold Word Tracking readiness gating
- Added readiness persistence coverage so the gate does not repeat after session stop
- Updated design, architecture, todo, and test documentation for the new startup behavior

## Installation And Updating

- First-time installs use the notarized DMG from the public release page.
- Installed beta copies are configured for Sparkle-based in-app updates.
- The DMG and Sparkle update archive correspond to the same shipped build.
