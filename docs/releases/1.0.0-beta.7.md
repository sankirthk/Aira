# Aira v1.0.0-beta.7

Tag: `v1.0.0-beta.7`  
Release date: `2026-05-07`

## Overview

This beta corrects the script progress indicator that was documented for beta 6 but was not included in the beta 6 DMG. It adds the persisted setting, live overlay wiring, and bottom-edge progress UI for Notch and Pill Window presenter sessions.

## Highlights

- **Script progress indicator is now included.** Active Notch and Pill overlays can show a thin bottom-edge progress line during presenter sessions.
- **Persisted System setting.** `Show script progress` is available in System > During Session and defaults off.
- **Live session updates.** Toggling the setting updates active overlay windows without requiring a new session.
- **No scroll behavior changes.** The indicator is visual only; it does not add a separate lane, intercept pointer input, or alter scroll math.

## Included In This Beta

### Script progress indicator

- Added `AppSettings.showScriptProgress`
- Added the System > During Session `Show script progress` toggle
- Wired the setting through Notch and Pill launch/update paths
- Rendered a 3pt bottom-edge progress line in `PrompterContentView`
- Used the current overlay text color for the progress fill
- Clamped progress fill to the visible `0...1` range
- Kept the indicator hidden during countdown

### Tests and docs

- Added settings persistence coverage for `showScriptProgress`
- Added controller update coverage for live session behavior
- Added progress-fill clamping coverage
- Updated design, test, and todo documentation for `REQ-040`

## Installation And Updating

- First-time installs use the notarized DMG from the public release page.
- Installed copies are configured for Sparkle-based in-app updates.
- The DMG and Sparkle update archive correspond to the same shipped build.
