# Aira v1.0.0

Tag: `v1.0.0`  
Release date: `2026-05-11`

## Overview

Aira 1.0.0 is the first stable release of Aira, a native macOS teleprompter built for presenters, podcasters, lecturers, interview prep, and video creators who want to stay on script without looking away from the camera.

This release graduates the final beta build to the stable channel. It is available as a notarized direct-download DMG and through the Mac App Store.

## Highlights

- **Word Matching Sync.** Offline, on-device speech recognition follows the words you are speaking using bundled WhisperKit models.
- **Sound Activated Scroll.** Aira can scroll while it hears speech activity and pause when the room goes quiet, with adjustable microphone sensitivity.
- **Notch Overlay.** The primary overlay sits near the camera and wraps around the built-in MacBook notch for natural eye contact.
- **Pill Windows.** Movable floating overlays can sit anywhere on screen, mirror the Notch session, or run separately selected scripts.
- **Stealth Mode.** Direct-distribution overlays can stay hidden from Zoom, Google Meet, Teams, and screen recordings.
- **Local-first script library.** Scripts stay on your Mac with collections, starring, drag-and-drop organization, and import support for PDF, DOCX, TXT, and Markdown.
- **Spoken-word highlighting.** Highlighting can visually track delivery in Word Matching Sync, Sound Activated Scroll, and Classic modes.
- **Script progress indicator.** Presenter sessions can show a thin progress line at the bottom edge of the overlay.
- **Appearance and readability controls.** Tune font, spacing, shadow, padding, overlay color, and per-overlay readability settings.
- **Signed stable updates.** Direct-distribution builds use Sparkle automatic updates over the signed stable channel.

## What's Included

### Voice-aware presenting

- Word Matching Sync with bundled offline speech models
- Fast startup readiness handling for cold Word Matching sessions
- Phrase recovery when speaking later visible text after skipping ahead
- Sound Activated Scroll as a local microphone-level motion mode
- Classic manual scrolling for traditional teleprompter pacing
- Word highlighting across all three session modes

### Overlay system

- Notch Overlay positioned near the built-in camera
- Pill Windows for movable display-specific prompting
- Mirrored and manual Pill Window session modes
- Undock and redock flow for the Notch Overlay
- Fullscreen support where the display setup supports it
- Screen-share-aware overlay behavior for direct-distribution builds

### Library and editing

- Local script library stored on-device
- Script creation, editing, duplicate, star, and delete actions
- Collections with drag-and-drop and context-menu management
- Import support for PDF, DOCX, TXT, and Markdown
- Empty-script launch guard

### Session controls

- Launch-time selection of scripts and Pill Windows
- Countdown before session start
- Real microphone mute for voice-aware modes
- Pause/resume controls and hover pause
- Keyboard shortcuts grouped by session workflow
- Script progress display

### Distribution

- Notarized direct-download DMG
- Mac App Store listing
- Sparkle-based automatic updates for direct-distribution builds
- Separate stable and beta Sparkle feeds

## Installation And Updating

- New users can install Aira from the Mac App Store or from the notarized direct-download DMG.
- Direct-distribution users receive updates through the stable Sparkle feed.
- Existing beta users should move to the stable `v1.0.0` release.

## Notes

- Aira requires macOS 14.4 or later.
- Aira does not require an account.
- Core presenter and authoring features are local-first.
- Word Matching Sync uses bundled on-device speech models.
