# Aira v1.0.0-beta.4

Tag: `v1.0.0-beta.4`  
Release date: `2026-04-21`

## Overview

This is a small follow-up beta focused on polish. `v1.0.0-beta.4` refines the direct-distribution updater prompt so the update experience feels more at home in Aira and gives the release UI a little more breathing room.

## Highlights

- **A roomier updater prompt.** The Sparkle update dialog now uses a larger window size so the branded copy and actions fit more comfortably.
- **Softer, more polished corners.** The updater prompt now uses a rounder card shape that better matches Aira's visual language.

## Included In This Beta

### Updater prompt polish

- Larger branded update prompt window
- Increased corner radius for the update card
- Slightly larger typography and spacing for a more relaxed layout

## Beta Scope

This beta is intentionally narrow:

- improve updater prompt presentation
- keep release behavior unchanged outside the prompt UI

## What To Pay Attention To

During this beta, the most valuable feedback is about:

- whether the update prompt feels easier to read at a glance
- whether the larger window size feels more balanced on screen
- whether the rounded card styling feels more consistent with the rest of Aira

## Installation And Updating

- First-time installs use the notarized DMG from the public release page.
- Installed copies are configured for Sparkle-based in-app updates.
- The DMG and Sparkle update archive correspond to the same shipped build.

## Notes

- This release is primarily a UI polish pass for the direct-distribution updater experience.
- Core teleprompter, library, and overlay behavior are otherwise unchanged from the prior beta.

## Site Changelog

- changed: The direct-distribution updater prompt now uses a larger window size for a more comfortable layout.
- changed: The updater prompt card now uses more rounded corners and roomier internal spacing.
