# Aira v1.0.0-beta.1

Tag: `v1.0.0-beta.1`  
Release date: `2026-04-17`

## Overview

This is the first public beta of Aira, a native macOS teleprompter built for presenters, podcasters, video creators, and anyone who needs to maintain eye contact while reading a script. Aira keeps the script close to the camera, stays hidden from screen sharing, and supports both speech-following and manual control.

This beta is focused on the main Aira workflow: create or import a script, organize it in the library, launch a presenter session, and run it in the Notch window or pill overlays.

## Highlights

- **Voice-Sync teleprompting.** Aira can follow your spoken words with on-device speech recognition and advance the script in real time.
- **Manual scrolling is always available.** You can drive the script yourself at any time with a configurable manual pace.
- **Stealth overlays for live sessions.** The Notch and pill overlays are designed to remain visible to you while staying out of screen-share output.
- **Notch-first presentation.** The primary teleprompter window is anchored beneath the built-in MacBook camera area for direct-to-camera delivery.
- **Optional pill overlays.** You can enable one or two additional floating pill windows and use them in synced or fully manual modes.
- **Built-in script workflow.** Aira includes a local-first document library, script editor, import flow, collections, starring, duplication, and bulk selection tools.

## Included In This Beta

### Presenter overlays

- Notch overlay anchored to the built-in display
- Pill overlays with support for one or two windows
- Shared overlay appearance controls for background color, text color, opacity, font size, and font family
- Lower reading zone layout for teleprompter readability
- Countdown before Voice-Sync begins
- Hover-pause interaction
- Keyboard pause/resume support for Voice-Sync sessions

### Voice-Sync and scrolling

- On-device speech recognition with no cloud dependency for core teleprompting
- Pause on silence behavior
- Smoothed shared playhead behavior for synced overlays
- Manual scroll speed controls when Voice-Sync is off
- Sync-mode pills that follow the active presenter session
- Manual-mode pills that can run independently from the Notch session

### Writing and library workflow

- Built-in script editor
- Inline cue insertion workflow
- Local-first JSON/file-backed storage
- Import for plain text, PDF, and DOCX files
- Duplicate script flow
- Starred scripts, recent scripts, and collection filtering
- Collection creation, rename, membership management, and deletion
- Multi-select and bulk delete in the document library

### App experience

- Manager interface for library, editing, and settings
- Settings for overlay behavior, pill count, and typography
- Stealth verification and warning path before presenter sessions
- Aira-branded update prompt flow for Sparkle-triggered updates

## Beta Scope

This first beta is intended to validate the core teleprompting experience:

- reading naturally from the Notch area
- running a live session with Voice-Sync
- falling back to manual scrolling when needed
- managing scripts without leaving the app
- verifying direct-distribution install and update behavior

It is not positioned as a feature-complete 1.0 launch. The focus is stability of the main presenter workflow and release pipeline.

## What To Pay Attention To

During this beta, the most valuable feedback is about:

- Voice-Sync pacing and matching accuracy during real speaking sessions
- readability of the Notch and pill overlays
- manual scroll comfort and speed tuning
- multi-window behavior across built-in and external displays
- stealth behavior during Zoom, Teams, Meet, and similar screen-share sessions
- document library and editing reliability during everyday use
- install, update, and relaunch behavior for direct-distribution builds

## Installation And Updating

- First-time installs use the notarized DMG from the public release page.
- Installed copies are configured for Sparkle-based in-app updates.
- The DMG and Sparkle update archive correspond to the same shipped build.

## Notes

- Aira is local-first. Core authoring and presenter workflows do not require an account or cloud service.
- Voice-Sync uses on-device recognition for the core experience.
- This is a beta release. Some polish, edge-case handling, and release automation details are still being tightened.
