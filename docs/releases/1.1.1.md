# Aira v1.1.1

Tag: `v1.1.1`  
Release date: 2026-05-22

## Overview

Aira 1.1.1 is a polish patch for the v1.1.0 Liquid Glass release. It fixes a font inconsistency in Classic mode and trims verbose copy in the Appearance settings panel.

## Highlights

- **Script title font fixed in Classic mode.** The script name field in the editor now uses Indie Flower in Classic mode, matching the rest of the Classic typography.
- **Cleaner Appearance settings.** Section descriptions and theme-card subtitles are trimmed or removed where they restated the obvious.

## Included In This Patch

### Script Editor

- Fixed script title `TextField` font in Classic mode — was `Manrope-Bold`, now `IndieFlower` to match Classic UI typography

### Settings — Appearance tab

- Removed redundant "Choose the Manager App color mode." description under Theme
- Removed theme card subtitles ("Light background with dark text." / "Dark background with light text.")
- Reduced theme card and Manager UI card heights to match trimmed content
- Shortened Palette description to "Accent colour for controls and highlights."
- Shortened Manager UI description to "How app chrome and surfaces are drawn."
- Shortened Classic and Liquid Glass interface style card descriptions

## Installation And Updating

- Direct-distribution users receive this update through the stable Sparkle feed.
- New users can install Aira from the notarized direct-download DMG.
- The DMG and Sparkle update archive correspond to the same shipped build.

## Notes

- This is a patch release from `v1.1.0`; the expected tag is `v1.1.1`.
- Aira requires macOS 14.4 or later.
- Core presenter and authoring features remain local-first.
