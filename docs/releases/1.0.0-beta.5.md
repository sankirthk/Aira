# Aira v1.0.0-beta.5

Tag: `v1.0.0-beta.5`  
Release date: `2026-04-21`

## Overview

This beta is a smaller follow-up polish pass focused on the Session settings experience, the Notch preview, and permission behavior. `v1.0.0-beta.5` renames and clarifies part of Settings, makes the font picker easier to use, brings the Notch preview closer to the real overlay, and tightens oversized control ranges so customization stays sensible.

This build also includes another attempt to reduce repeated permission prompts, especially around launch-time accessibility, microphone, and speech-recognition checks.

## Highlights

- **System is now Session.** The settings area is labeled more clearly around how the app is actually used.
- **The font row is easier to use.** Clicking anywhere on the overlay font row now opens the dropdown instead of requiring a precise click on the smaller control.
- **The Notch preview is more faithful.** Preview sizing now better reflects the real overlay instead of exaggerating the notch cutout or vertical sizing.
- **Overlay controls are now bounded to realistic values.** Width, height, and font size are clamped into tighter ranges so the settings do not drift into impractical extremes.

## Included In This Beta

### Settings and naming polish

- Renamed the **System** settings section to **Session**
- Improved the overlay font picker row so the whole row behaves as the dropdown trigger

### Notch preview improvements

- Updated the preview layout to better match the real live overlay
- Reduced unrealistic preview behavior where width changes made the notch cutout appear too large
- Improved height representation so the preview feels closer to what appears during a real session

### Overlay control tightening

- Clamped notch width to a tighter practical range
- Clamped notch height to a tighter practical range
- Clamped overlay font size to a tighter practical range
- Updated default values so the controls start from more reasonable middle-ground settings

### Permission flow work

- Continued refining launch-time permission behavior
- Reduced unnecessary re-request paths for accessibility checks
- Tightened speech and microphone request logic so prompts are intended to happen only when permissions are still undetermined

## Beta Scope

This beta is intentionally narrow:

- improve clarity inside Settings
- make overlay controls easier to use and harder to misconfigure
- improve confidence in the Notch preview before starting a session
- reduce permission-related friction during repeated launches

## What To Pay Attention To

During this beta, the most valuable feedback is about:

- whether renaming **System** to **Session** makes the settings structure easier to understand
- whether the full-row font picker interaction feels more natural
- whether the Notch preview now feels closer to the actual overlay once a session starts
- whether the tighter width, height, and font-size ranges still feel flexible enough
- whether accessibility, microphone, and speech-recognition prompts stop appearing unnecessarily after permission has already been granted

## Installation And Updating

- First-time installs use the notarized DMG from the public release page.
- Installed copies are configured for Sparkle-based in-app updates.
- The DMG and Sparkle update archive correspond to the same shipped build.

## Notes

- This release is primarily a polish and behavior-tuning beta rather than a feature expansion release.
- Permission behavior may still vary in local development builds if macOS treats different local builds as distinct app identities.
