# Aira v1.1.0

Tag: `v1.1.0`  
Release date: 2026-05-22

## Overview

Aira 1.1.0 is a visual and usability update for the Manager App and presenter overlays. It introduces a Liquid Glass Manager interface, adds blue and purple accent treatments, brings optional Frosted Glass surfaces to the Notch and Pill Windows, and fixes forward navigation in the Manager window.

## Highlights

- **Liquid Glass Manager UI.** The Manager App now supports a glass-styled interface with refreshed typography, materials, sidebar treatment, and window chrome.
- **Blue and purple accents.** The updated visual system adds blue and purple accent treatments across selected controls and polished Manager surfaces.
- **Optional Frosted Glass overlays.** The Notch and Pill Windows now include Frosted Glass settings so presenters can choose a translucent overlay style.
- **Forward navigation fix.** The Manager forward arrow is now wired up, so back/forward navigation works as expected.
- **Library card polish.** Long script titles now stay on one line with tail truncation to keep cards aligned at the minimum window size.

## Included In This Release

### Manager App visual system

- Added Liquid Glass Manager UI support with native transparent titlebar handling
- Refined sidebar, settings, document library, editor, and button styling for the new glass mode
- Added blue and purple accent treatments to the refreshed Manager interface
- Preserved Classic mode while keeping layout stable when switching Manager UI styles

### Notch and Pill Window appearance

- Added Frosted Glass settings for both the Notch and Pill Windows
- Routed overlay content through transparent/frosted background handling when Frosted Glass is enabled
- Aligned Frosted Glass settings typography and placement with the surrounding Overlay Feel controls

### Navigation and interaction fixes

- Wired the Manager forward navigation button so it can move through navigation history
- Fixed drag-and-drop behavior in the content area
- Improved titlebar, traffic-light positioning, click handling, and fullscreen prevention
- Kept script-card titles aligned by truncating long names with a tail ellipsis

## Installation And Updating

- Direct-distribution users receive this update through the stable Sparkle feed.
- New users can install Aira from the Mac App Store or from the notarized direct-download DMG.
- The DMG and Sparkle update archive correspond to the same shipped build.

## Notes

- This is a feature release from `v1.0.1`; the expected tag is `v1.1.0`.
- Aira requires macOS 14.4 or later.
- Core presenter and authoring features remain local-first.
