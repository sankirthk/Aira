# Aira v1.1.4

Tag: `v1.1.4`  
Release date: 2026-05-23

## Overview

Aira 1.1.4 is a patch that fixes frosted glass disappearing when the Notch window is undocked. Frosted glass now stays active regardless of dock state.

## Highlights

- **Frosted glass persists after undock.** Enabling Frosted Glass in settings now keeps the effect active whether the Notch window is docked, undocked, or in undocked fullscreen.

## Included In This Patch

### Notch Window — Frosted Glass

- Removed the `isDocked` guard from `usesFrostedGlass` in `NotchContentView`
- `OverlayFrostedGlassBackground` clips to the active content shape (`notch` when docked, `roundedRectangle` when undocked), so the effect renders correctly in both states
- Re-docking with frosted glass enabled continues to work as before

## Installation And Updating

- Direct-distribution users receive this update through the stable Sparkle feed.
- New users can install Aira from the notarized direct-download DMG.

## Notes

- This is a patch release from `v1.1.3`; the expected tag is `v1.1.4`.
- Aira requires macOS 14.4 or later.
- Core presenter and authoring features remain local-first.
