# Aira v1.1.4

Tag: `v1.1.4`  
Release date: 2026-05-24

## Overview

Aira 1.1.4 is a UI polish and consistency release. It fixes the frosted glass regression from 1.1.3, brings the Manager app's Liquid Glass mode to full visual parity — every selected state, button fill, and surface now uses the glass treatment — and replaces the document library's checkbox selection model with a native macOS Finder-style interaction.

## Highlights

- **Frosted glass persists after undock.** Enabling Frosted Glass in settings keeps the effect active whether the Notch window is docked, undocked, or in undocked fullscreen.
- **App theme applies everywhere.** Error modals and the delete-collection confirmation now correctly inherit the active theme (palette, accent, and glass/classic mode) instead of always rendering in the default Aira style.
- **Glass mode fully styled.** All selected states, action buttons, and surfaces in the Manager app — settings cards, alignment buttons, scroll mode cards, swatch tiles, sidebar tabs, and section panels — now use frosted glass treatment when Liquid Glass mode is active.
- **Finder-style script selection.** The document library drops checkboxes entirely. Single click opens, ⌘+click and ⇧+click select, right-click brings a context menu, and the Delete key removes selected scripts.

## Included In This Release

### Notch Window — Frosted Glass

- Removed the `isDocked` guard from `usesFrostedGlass` in `NotchContentView`
- `OverlayFrostedGlassBackground` now clips to the active content shape in both docked and undocked states

### Manager App — Theme Propagation

- Moved `.environment(\.managerTheme, …)` to be the outermost modifier on `ManagerWindowView.body`, so all overlays — including error popups and delete-collection confirmations — inherit the correct theme
- `AiraMessagePopup` dismiss button now uses `AiraCardCastButtonStyle` in both glass and classic modes, replacing the system-blue pill shape

### Document Library — Native Selection Model

- Removed the checkbox and Select All bar entirely
- Single click opens the script editor; ⌘+click and ⇧+click toggle and range-select cards
- Right-click on any card shows a full context menu (Edit, Star/Unstar, Add to Collection, Cast, Delete); right-click when multiple scripts are selected shows Delete only
- Each card shows a `…` hover button exposing the same menu without requiring right-click
- Delete key removes all selected scripts after confirmation
- Escape clears the selection

### Settings — Liquid Glass Selected States

- Sidebar tab active state: `ultraThinMaterial` + accent tint + accent stroke border (replaces solid accent fill)
- All selection cards throughout settings now use the frosted glass pattern in Liquid Glass mode: appearance theme cards, interface style cards, typography size buttons, alignment buttons, scroll mode cards, swatch tiles, satellite count and slot buttons
- Action buttons (Reset to Defaults, Use Notch Defaults) use the glass treatment in Liquid Glass mode
- Keyboard shortcut keycaps rendered in accent color (fill, border, text) in light mode; white text with accent fill and border in dark mode
- Settings sidebar and content area glass opacity increased for better legibility
- Settings panel borders strengthened in classic light mode (`0.22` opacity) and glass light mode (`0.20` opacity)
