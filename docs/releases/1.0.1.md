# Aira v1.0.1

Tag: `v1.0.1`  
Release date: 2026-05-12

## Overview

Aira 1.0.1 is a targeted stability update for Word Matching Sync during real video calls. It improves recognition of quiet, call-processed microphone audio so the teleprompter can keep matching spoken words without requiring you to raise your voice.

## Highlights

- **Better recognition during calls.** Word Matching Sync now accepts usable Zoom and call-processed speech that previously sat below the recognition preprocessing floor.
- **Stronger bounded gain for quiet speech.** Aira boosts valid low-level microphone input more aggressively before speech recognition while keeping noise rejection in place.
- **Regression coverage for call audio.** The test suite now covers call-processed speech levels below the old gate.

## Included In This Patch

### Voice sync recognition

- Lowered the recognition pre-gain input floor for usable call-processed speech
- Increased the bounded recognition gain for quiet but valid microphone input
- Preserved lower environmental-noise rejection behavior

### Tests and docs

- Added a focused regression test for low call-processed speech input
- Updated the voice-sync test plan and task tracking notes

## Installation And Updating

- Direct-distribution users receive this update through the stable Sparkle feed.
- New users can install Aira from the Mac App Store or from the notarized direct-download DMG.
- The DMG and Sparkle update archive correspond to the same shipped build.

## Notes

- This is a patch release for existing voice-sync behavior, not a feature release.
- Aira requires macOS 14.4 or later.
- Core presenter and authoring features remain local-first.
