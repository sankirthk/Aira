# Aira v1.0.0-beta.6

Tag: `v1.0.0-beta.6`  
Release date: `2026-05-07`

## Overview

This beta is the largest presenter-session update so far. `v1.0.0-beta.6` adds offline Word Matching Sync powered by bundled WhisperKit models, revamps session launch so Pill Windows are chosen at launch time, and gives each Pill Window its own appearance/readability controls.

It also tightens the everyday presenter controls: microphone mute now actually stops capture, Escape behaves correctly around fullscreen, manager-window traffic lights return after a session, empty scripts are blocked from launching, and word highlighting is much faster to acquire and recover when the speaker skips ahead.

## Highlights

- **Offline Word Matching Sync.** Aira now uses bundled WhisperKit models for word-based script tracking, with no runtime model download and no cloud speech processing.
- **Launch-time Pill Window setup.** Pill Windows are now chosen when you cast, instead of forcing users to preconfigure every session from Preferences.
- **Per-Pill Window customization.** Each Pill Window can have its own appearance and readability settings while still inheriting sensible Notch defaults when untouched.
- **Faster, more resilient word highlighting.** Highlighting now locks onto the starting words more quickly and can recover from skipped lines when the next visible phrase is spoken.
- **Real microphone mute.** The microphone button now mutes and resumes audio capture instead of only pausing scroll movement.
- **Cleaner session recovery.** Escape handling, fullscreen passthrough, and manager-window traffic-light restoration are fixed after presenter sessions.
- **More realistic scroll speeds.** Classic scroll speed now uses a tighter 10-30 points-per-second range with a default of 10.
- **Better hit targets.** Split buttons, reset buttons, dropdown rows, and color swatches now respond across the whole visible control instead of only the centered text or tiny picker area.
- **Optional script progress.** Presenter overlays can show script progress so users can see where they are in the script at a glance.

## Included In This Beta

### Word Matching Sync

- Added WhisperKit as the offline word-matching backend
- Bundled `openai_whisper-base.en` for primary local recognition
- Kept `openai_whisper-tiny.en` as a bundled fallback model
- Disabled runtime WhisperKit model downloads
- Added a fakeable speech backend boundary so word matching can be tested without loading Core ML
- Converted microphone capture into 16 kHz mono recognition input before transcription
- Added low-volume noise gates so background noise is not amplified into speech-like input
- Split recognition policy by scroll mode:
  - Word Matching Sync uses WhisperKit for scroll and highlight alignment
  - Sound activated scrolling uses local microphone levels for motion
  - Classic mode stays manual unless word highlighting is enabled
  - Classic and Sound activated word highlighting use the Apple on-device speech-recognition path

### Word highlighting and recovery

- Made startup highlighting acquire the first spoken words faster
- Added phrase recovery so speaking a later visible line can move the highlight anchor after a missed section
- Allowed 2+ word visible-window recovery without letting random repeated words jump the playhead
- Preserved the dull-prefix/highlight state across short recognition pauses
- Scoped highlights to the active script so swapped Notch/Pill content cannot show stale highlights from another script
- Isolated Sound activated scroll ticks from the Apple speech highlight cursor
- Improved call-route and meeting-app microphone handling so voice features remain responsive while another app is using the mic

### Session launch revamp

- Moved Pill Window content selection into the launch flow
- Added chevron launch controls from the Script Editor
- Added chevron launch controls from script overview cards
- Added `Cast with Pill Windows` as an explicit secondary launch path
- Added a Pill Window assignment panel with one section per enabled Pill Window
- Supported mirrored Pill Windows that follow the current Notch session
- Supported manual Pill Windows that launch a separately selected script
- Skipped invalid or empty Pill Window assignments instead of silently opening empty windows
- Added a guard so empty or whitespace-only scripts cannot start an empty presenter session
- Kept `Cast to Notch` as the direct, default launch action

### Pill Window customization

- Added per-Pill Window appearance/readability overrides
- Kept untouched Pill Windows inheriting shared Notch defaults
- Moved Pill Window launch content out of Preferences so Settings controls configuration, not one-time launch choices
- Preserved the Pill Window count setting so launch panels show one or two slots
- Added per-window chrome behavior so synced Pill Windows, manual Pill Windows, and voice-driven overlays reflect what they are actually doing

### Presenter controls and overlays

- Added an optional script progress indicator
- Made the microphone button mute and resume microphone capture
- Added a separate pause/resume button for Classic mode when word highlighting is enabled
- Fixed Escape so it can still pass through to macOS fullscreen while ending presenter sessions correctly
- Restored manager-window traffic lights after a session ends
- Preserved fullscreen manager windows instead of forcing app-style changes during session launch/end
- Fixed session scroll shortcut routing so Manual Pill Windows do not move from shared Notch shortcuts
- Kept Pill Window hover behavior independent from the Notch hover-pause setting

### Settings and interaction polish

- Reduced Classic scroll speed to a practical 10-30 points-per-second range
- Set the default Classic scroll speed to 10 points per second
- Made split-button chevron regions fully clickable
- Made settings reset buttons clickable across the whole visible button
- Made custom color swatches clickable across the whole tile
- Fixed custom color swatches so clicking anywhere opens the system color picker
- Kept font defaults hard-coded to Aira's intended app fonts after removing the experimental system-font setting
- Enabled microphone sensitivity controls for the modes that actually use the microphone

### Reliability and sandbox fixes

- Upgraded the user-selected file entitlement to read-write
- Replaced blocking `NSSavePanel.runModal()` log export with sheet-based presentation for sandbox compatibility
- Kept menu bar quick access visible and above other apps
- Fixed menu bar launches so they respect the selected voice mode
- Improved script-launch API boundaries so notch-only, mirrored Pill Window, and assigned Pill Window sessions use explicit launch intents

## Beta Scope

This beta is intentionally broad:

- add offline Word Matching Sync
- make launch-time Pill Window selection practical
- make per-Pill Window customization real
- improve word highlighting startup and recovery
- make microphone mute, pause, Escape, fullscreen, and manager-window restore behavior more predictable
- tighten scroll speed and interaction hit targets before wider testing

## What To Pay Attention To

During this beta, the most valuable feedback is about:

- whether Word Matching Sync follows real speech naturally without jumping to repeated words
- whether highlighting starts quickly enough at the beginning of a script
- whether highlighting recovers correctly when you skip a few lines and start speaking later visible text
- whether the new Pill Window launch panel makes more sense than configuring content in Preferences
- whether per-Pill Window appearance/readability settings are easy to understand
- whether the microphone button feels like a true mute control
- whether the separate Classic pause button avoids confusion when word highlighting is enabled
- whether Escape and fullscreen behavior feel native after a session ends
- whether the 10-30 points-per-second scroll range feels practical
- whether the full-button and full-swatch hit targets remove the previous precision-click issues

## Installation And Updating

- First-time installs use the notarized DMG from the public release page.
- Installed copies are configured for Sparkle-based in-app updates.
- The DMG and Sparkle update archive correspond to the same shipped build.

## Notes

- Word Matching Sync is fully offline and uses bundled speech models. The larger app size is expected for this beta.
- Core presenter features still require no account, no telemetry, and no cloud service.
- Direct-distribution builds may still use Sparkle over HTTPS for update checks and signed update downloads.
- Word Matching Sync, Sound activated scrolling, Classic scrolling, and word highlighting now have different behavior by design; testing all combinations is especially useful in this beta.
