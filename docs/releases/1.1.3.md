# Aira v1.1.3

Tag: `v1.1.3`  
Release date: 2026-05-23

## Overview

Aira 1.1.3 is a settings polish patch. It keeps the Pill Windows settings preview fixed at the top of the tab, matching The Notch settings behavior, while Pill Window controls scroll below it.

## Highlights

- **Pill Windows preview stays fixed.** The Pill Windows settings preview now remains pinned at the top of the tab instead of moving away while scrolling through appearance and readability controls.
- **Settings layout matches The Notch.** The Pill Windows tab now uses the same fixed-preview layout pattern as The Notch tab, keeping preview feedback visible while tuning controls.

## Included In This Patch

### Settings — Pill Windows tab

- Moved the Pill Windows tab to the same static outer settings container used by The Notch tab
- Kept the Pill Windows preview outside the scrollable controls region
- Preserved scrolling for the Pill Window count, slot, color, feel, font, and readability controls
- Added focused settings affordance coverage for the fixed-preview container policy
