# Aira v1.1.2

Tag: `v1.1.2`  
Release date: 2026-05-23

## Overview

Aira 1.1.2 is a bug-fix patch. It fixes IndieFlower font leaking into Liquid Glass mode in the empty-state library views, and fixes the sidebar traffic light buttons being invisible (but still clickable) on macOS 14.4.

## Highlights

- **Liquid Glass font consistency.** Empty library views (no scripts yet, filtered-empty states) now use the correct system font in Liquid Glass mode instead of falling back to IndieFlower.
- **Traffic lights visible on macOS 14.4.** Sidebar close/miniaturize/zoom buttons shifted out of the titlebar container's clip rect were invisible on macOS 14.4. Clipping is now disabled on the ancestor views so the repositioned buttons remain visible.

## Included In This Patch

### Document Library — empty states

- `EmptyLibraryView` and `EmptyFilteredLibraryView` now read `managerTheme` from the environment and switch to system fonts when Liquid Glass mode is active, matching the rest of the library UI

### Sidebar — traffic lights (macOS 14.4)

- After repositioning the native traffic light buttons, `disableClippingOnTitlebarAncestors` walks the superview chain and sets `masksToBounds = false` on each intermediate view so buttons remain visible outside the titlebar container's clip bounds
