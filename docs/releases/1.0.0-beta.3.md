# Aira v1.0.0-beta.3

Tag: `v1.0.0-beta.3`  
Release date: `2026-04-20`

## Overview

This beta sharpens Aira's day-to-day presenter workflow across the library, settings, overlays, and menu bar experience. The focus in `v1.0.0-beta.3` is better script organization, more explicit session controls, more flexible overlay behavior, and a round of stability fixes to remove friction during repeated live sessions.

Compared with the first beta, this release gives users more ways to organize scripts into collections, separates Notch and Pill preferences more clearly, adds accessibility-focused readability controls, and replaces several hidden or context-menu-only overlay actions with visible hover controls. This build also corrects the direct-distribution update path so future beta releases publish with a newer Sparkle build number and the proper beta feed metadata.

## Highlights

- **Collections are faster to manage.** Scripts can now be added to collections from a hover action, by dragging onto a collection in the sidebar, or from a script-card context menu.
- **Settings are reorganized around real session flow.** Pill preferences now live in their own tab, Notch settings are more focused, and System settings are grouped into Before Your Session, During Your Session, Controls, and Privacy.
- **Overlay readability is more configurable.** The Notch settings now include accessibility controls for letter spacing, line spacing, word spacing, text shadow, and inner text padding.
- **Scrolling behavior is more stable and explicit.** Manual auto-scroll now uses points per second instead of WPM-style pacing, and spoken-word highlighting is available as a visual-only session aid.
- **Overlay controls are now visible on hover.** The Notch and Pill overlays replace most context-menu actions with direct hover buttons for pause, close, docking, swapping, and fullscreen where supported.
- **The Notch can now undock into a free-floating overlay.** When no Pill windows are active, the Notch overlay can detach from the camera area, move freely, resize, enter fullscreen, and dock back smoothly.

## Included In This Beta

### Library and collections

- Hover-action entry point to add a script to one or more collections
- Collection manager modal with multi-collection selection and inline collection creation
- Drag-and-drop support for dropping script cards onto collection rows in the sidebar
- Script-card context menu with duplicate, star/unstar, add-to-collection, and delete actions

### Preferences and settings

- Separate Pill tab instead of nesting pill settings under the Notch area
- Notch settings updated to remove mood presets
- Accessibility controls for overlay readability:
  - letter spacing
  - line spacing
  - word spacing
  - text shadow
  - text padding
- Reorganized System tab with sections for:
  - Before Your Session
  - During Your Session
  - Controls
  - Privacy

### Session controls and pacing

- Countdown timer configuration before a session starts
- Manual scroll speed shown and stored in `pt/s` for more stable physical pacing
- Voice-activated tracking sensitivity controls retained in the During Your Session section
- Spoken-word highlighting added as an optional visual-only feature that does not change actual scroll speed
- Pause on mouse hover promoted to an explicit user setting instead of being an unconfigurable default behavior
- Keyboard shortcuts grouped under Controls
- Privacy toggle for whether overlays remain hidden from screen sharing or are intentionally shareable

### Overlay interaction updates

- Hover-button chrome for active overlays instead of relying on context menus
- Notch hover controls for close and pause or microphone mute, depending on session mode
- Notch undock control enabled only when the Notch is the only overlay and no Pills are active
- Smooth dock/undock flow for the Notch overlay, with resize and fullscreen support while undocked
- Pill hover controls for swap, fullscreen, and close
- Swap disabled for synced Pill sessions
- Pill fullscreen enabled only when it makes sense for the current display configuration

### App polish and bug fixes

- Menu bar icon now adapts between black and white to match the menu bar appearance
- Script library blanking after a presenter session has been fixed
- Menu bar quick-access dismissal is easier and now closes when clicking elsewhere on screen
- Direct-distribution release automation now publishes beta updates on a dedicated Sparkle beta feed with monotonically increasing build numbers

## Beta Scope

This beta continues to focus on the main presenter loop:

- organize scripts quickly
- configure overlays with clearer settings boundaries
- launch sessions with more predictable pacing
- adjust overlay behavior directly during a live session
- reduce friction when moving between manager, menu bar, and presenter overlays

The emphasis here is workflow polish and control clarity rather than expanding the app into new product areas.

## What To Pay Attention To

During this beta, the most valuable feedback is about:

- whether the new collection-management flows feel faster than the previous library workflow
- whether the Notch and Pill settings split is clearer during setup
- readability and comfort of the new accessibility controls during long reading sessions
- whether `pt/s` pacing feels more predictable than prior manual speed tuning
- usefulness of spoken-word highlighting as a visual aid during Voice-Sync sessions
- how well the new Notch undock and redock behavior fits real presenter setups
- whether hover-button overlay controls are easier to discover and use than context menus
- whether installed beta builds now discover new beta updates correctly through Sparkle

## Installation And Updating

- First-time installs use the notarized DMG from the public release page.
- Installed copies are configured for Sparkle-based in-app updates.
- Beta direct-distribution builds now follow the dedicated Sparkle beta feed instead of the stable feed.
- The DMG and Sparkle update archive correspond to the same shipped build.

## Notes

- Aira remains local-first, with core writing and presenter workflows staying on device.
- Overlay privacy remains hidden-by-default for screen sharing unless the user explicitly chooses to share overlays.
- This is still a beta release, with continued emphasis on stability, polish, and presenter comfort.
